# Backend FlexHotel API

API REST para gerenciamento de hotel com Prisma, Express e PostgreSQL.

## Features
- Autenticacao com JWT
- Controle de roles
- CRUD de usuarios, hoteis, quartos, reservas e estadias
- Validacao com Zod
- Hash de senhas com bcryptjs

## Instalacao
```bash
npm install
npm run prisma:migrate
npm run seed
```

## Desenvolvimento
```bash
npm run dev
```
